# Contributing

Thank you for helping make space and engineering education more accessible.

## Ways to contribute

- Translate content between Arabic and English
- Add project briefs
- Improve accessibility and mobile usability
- Add simulations or calculators
- Review technical accuracy
- Pilot a curriculum and report classroom feedback

## Contribution workflow

1. Fork the repository.
2. Create a descriptive branch.
3. Make one focused change.
4. Test the web app in both languages.
5. Submit a pull request explaining the educational value.

## Content standards

Project briefs should include:

- Real-world problem
- Student age or skill level
- Mission objective
- Required outputs
- Constraints
- Evaluation criteria
- Safety or ethics notes where relevant

Avoid claims that a student project is flight-ready, medically validated, or suitable for real-world deployment unless it has been independently verified.
